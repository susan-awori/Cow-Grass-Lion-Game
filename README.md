# Cow, Grass and Lion 🦁🐮🌿

A JavaScript-based strategy game that gamifies the ecosystem food chain. This project puts a biological spin on the classic "Rock, Paper, Scissors" mechanic.

## 🎮 How it Works (The Food Chain Logic)

The game relies on a cyclic food chain logic:

* **Lion eats Cow** 🦁 > 🐮
    * *(The Predator hunts the Prey)*
* **Cow eats Grass** 🐮 > 🌿
    * *(The Herbivore grazes on the Producer)*
* **Grass defeats Lion** 🌿 > 🦁
    * *(The Cycle of Nature: A Lion cannot eat grass, and upon death, it decomposes to feed the grass and soil)*

## ✨ Current Features (Commit Status)

* **Core Logic Complete:** The JavaScript functions correctly determine the winner of each round (currently displayed via alert boxes).
* **Full Responsive Controls:** All three action buttons are designed to adjust and display correctly on mobile, tablet, and desktop screens.
* **Clean Structure:** All primary HTML elements are in place.

## 🛠️ Technologies Used

* **HTML5:** Structure of the game board.
* **JavaScript (ES6):** Game logic, event handling, and result determination.

## 🚀 How to Run

1.  Clone the repository or download the files.
2.  Open `Game.html` in your web browser.
3.  Click on **Cow**, **Grass** or **Lion** to make your move.
