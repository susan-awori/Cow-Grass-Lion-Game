# Cow, Grass and Lion 🦁🐮🌿

A JavaScript-based strategy game that gamifies the ecosystem food chain. This project puts a biological spin on the classic "Rock, Paper, Scissors" mechanic.

## 🎮 How it Works (The Food Chain Logic)

The game relies on a cyclic food chain logic:

- **Lion eats Cow** 🦁 > 🐮 (The Predator hunts the Prey)
- **Cow eats Grass** 🐮 > 🌿 (The Herbivore grazes on the Producer)
- **Grass defeats Lion** 🌿 > 🦁 (The Cycle of Nature: A Lion cannot eat grass, and upon death, it decomposes to feed the grass and soil)

## ✨ New Features

- **Dynamic UI Display:** Replaced browser alert boxes with a dedicated "Game Console" for real-time result updates.
- **Interactive Design:** 3D-styled buttons with hover and active states for a tactile gaming experience.
- **Color-Coded Feedback:** Results are styled with distinct colors (Green for Wins, Red for Losses) to provide immediate visual feedback.
- **Fully Responsive:** Optimized for a seamless experience across mobile, tablet, and desktop screens.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure for the game board.
- **CSS3:** Custom styling, Flexbox layout, and button animations.
- **JavaScript (ES6):** Game logic, DOM manipulation, and event handling.
